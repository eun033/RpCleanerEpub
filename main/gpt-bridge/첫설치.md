처음 설치만 진행할 것. 기존 서버를 쓰고 있다면 관리 화면의 업데이트를 우선 사용함. ZIP과 Git 중 하나만 선택. GitHub 계정은 공개 저장소 설치에 필요 없음. Node.js 22 이상 필요.

[Windows — ZIP]
Node.js LTS 설치: https://nodejs.org/
PowerShell에서 버전 확인:
node --version

최신 ZIP을 내려받아 압축 해제 후 start-windows.bat 더블클릭.
실행 창은 유지하고 표시된 주소를 같은 PC 브라우저에서 열기.
다음 실행도 동일한 BAT 파일 사용.

[Windows — Git]
Node.js 22 이상 및 Git 설치 후 PowerShell에서 한 줄씩:
cd $HOME
git clone --depth 1 https://github.com/eun033/RpCleanerEpub.git
cd "$HOME\RpCleanerEpub\main\gpt-bridge"
.\start-windows.bat

기존 clone을 수동 갱신할 때 서버를 먼저 종료하고:
cd "$HOME\RpCleanerEpub"
git pull --ff-only origin main
cd main\gpt-bridge
.\start-windows.bat

[iOS — iSH ZIP]
iSH 전용 환경에서 다음 명령을 한 줄씩 실행.
설치 스크립트는 Alpine 패키지 저장소 설정을 백업하고 Alpine 3.22 및 호환 계층을 구성함.
apk update
apk add curl unzip
cd /root
curl -fL -o GPT_Bridge.zip https://raw.githubusercontent.com/eun033/RpCleanerEpub/main/main/gpt-bridge/GPT_Bridge.zip
unzip -o GPT_Bridge.zip
cd gpt-bridge
sh install-ish.sh

이후 다시 실행:
sh ~/local-gpt-subscription-bridge/start-ish.sh

[AOS — Termux ZIP]
Termux: https://f-droid.org/packages/com.termux/
pkg update
pkg install nodejs-lts unzip curl
cd ~
curl -fL -o GPT_Bridge.zip https://raw.githubusercontent.com/eun033/RpCleanerEpub/main/main/gpt-bridge/GPT_Bridge.zip
unzip -o GPT_Bridge.zip
cd gpt-bridge
bash install-termux.sh

[AOS — Termux Git]
pkg update
pkg install git nodejs-lts
cd ~
git clone --depth 1 https://github.com/eun033/RpCleanerEpub.git
cd RpCleanerEpub/main/gpt-bridge
bash install-termux.sh

[AOS — 다시 실행 / 중지]
bash ~/local-gpt-subscription-bridge/start.sh
중지는 Ctrl+C.

[AOS — 기존 공개 Git 설치판 수동 업데이트]
진행·대기 작업을 끝내고 기존 서버 종료 후 실행.
cd ~/RpCleanerEpub
git pull --ff-only origin main
cd main/gpt-bridge
bash update-termux.sh
bash ~/local-gpt-subscription-bridge/start.sh

[AOS — 기존 ZIP 설치판 수동 업데이트]
진행·대기 작업을 끝내고 기존 서버 종료 후 실행.
cd ~
curl -fL -o GPT_Bridge.zip https://raw.githubusercontent.com/eun033/RpCleanerEpub/main/main/gpt-bridge/GPT_Bridge.zip
unzip -o GPT_Bridge.zip
cd gpt-bridge
bash update-termux.sh
bash ~/local-gpt-subscription-bridge/start.sh
