- Git·ZIP 업데이트와 재시작: 저장 차단·수동 코드 연결, 이전 서버→일시 접속 실패→새 서버 전환, 연결 코드 보존, 업데이트 응답 유실 시 POST 중복 방지를 계속 검사한다.
